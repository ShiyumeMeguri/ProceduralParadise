# Conservatory — 水晶幻想 · 水晶温室

一座漂浮在星海中的维多利亚式玻璃温室：中央圆厅是光之柱与倒影池，四条中殿分别是垂挂浅碗的中庭、
紫色大丽花的玻璃展柜长廊、宝石与宝珠的多层玻璃架长廊、银河宝珠花园。氛围取自五张 AI 生成的角色插画
（未收录进仓库），场景里没有角色；插画里前后矛盾、不能成立的结构全部按真实 3D 空间重新设计。

渲染结果：`Renders/<镜头>.png`（五个英雄机位，1496 × 1160，160 采样）与 `Renders/view_*.png`（七个自由机位，
1920 × 1080 渲染后缩到 1280 × 720）。

```bash
blender -b -P FractalWorld/build.py                                              # 构建并保存 .blend
blender -b -P FractalWorld/build.py -- --shot HangingGarden --render garden.png  # 英雄机位
blender -b -P FractalWorld/build.py -- --view overlook --render overlook.png     # 自由机位
blender -b -P FractalWorld/build.py -- --render-animation                        # 巡游视频
```

全部几何来自 `CrystalFantasy/Kit` 的几何节点资产，场景只是数据（`scene.json`）；参考图只用来定氛围与构图，
渲染时从不采样，没有任何投影贴图。

## 1. 空间布局（世界坐标：原点 = 圆厅地面中心，+Y 北，+X 东，Z 向上，米）

* **圆厅**：16 边形，外接圆半径 9 m，鼓座高 12 m，玻璃穹顶再高 7 m，顶上灯笼亭。四个方向各拆去正对的三面，
  以平面门廊接中殿（门廊在 7.483 m 处，门洞就是中殿的拱形截面）。地面是下沉 0.14 m 的倒影池，水面 z = −0.035，
  沿墙留 0.7 m 的石质步道。
* **四条中殿**：宽 10 m、长 22 m、墙高 6 m、半圆玻璃拱顶（拱顶 11 m），铁肋每 2.5 m 一道，石质墙基；尽端是拱形玻璃山墙。
  * 北 · **垂挂花园中庭**：门廊后 1.2 m 是一道粗铁格玻璃屏风（中间拱门），后面是从拱顶垂下的浅碗链，两侧花坛，尽端一颗发光晶心。
  * 东 · **玻璃展柜长廊**：36 座玻璃展柜塔（4–6 层），紫色大丽花、睡莲与玫瑰；这一段拱顶用淡紫色的星光玻璃。
  * 西 · **多层玻璃架长廊**：同样隔一道屏风；13 座等比多层玻璃架摆满银河宝珠、行星宝珠、明亮式宝石与晶簇，两侧与屏风后是玫瑰花坛。
  * 南 · **宝珠花园与入口**：两条长花坛与中间的岛状花坛，岛中央是一座内部发光的沃德箱（维多利亚玻璃植物箱）；尽端是入口大门。
* **室外**：温室立在 36 m 的多边形石台上，台阶一圈圈下到海面（z = −2.2）；海面像镜子，远处 170–800 m 的等面积黄金角圆环上
  立着 36 座 60–240 m 高的发光晶塔；天空是星点与星云带。

## 2. 参考图里"反 3D"的结构与处理

原则：**在 3D 里是能成立、能自由换机位的空间；在对应的英雄机位下尽量接近参考图的构图与氛围。**

| 参考图现象 | 处理 |
|------------|------|
| 浅碗凭空悬浮、上下错落 | 碗串在一根细杆上，从中殿拱顶垂下（锚点按拱顶曲线算）；每串 2–4 只，逐层按等比数列缩小、间距收缩；碗底挂水晶滴 |
| 玻璃多层架的托盘凭空叠放 | 中心一根玻璃立杆贯穿，托盘半径按等比递减，立在圆形玻璃底座上 |
| 药剂罐一个压一个、大小关系混乱 | 大罐不加盖，小罐的底足正好坐在大罐口沿上；其余罐子分内外两圈立在池水里 |
| 玻璃展柜的透视互相矛盾、层层叠叠没有支撑 | 每层是一只玻璃箱立在比它宽一圈的厚玻璃搁板上，逐层微转、微错位，顶上再压一块搁板；塔按网格排成四列，中间留通道 |
| 宝珠漂在空中、底下拖着尖尾 | 宝珠长在植物细茎顶端，尖尾就是与茎相连的水滴状接口；茎从一丛叶莲座里抽出 |
| 背后画出一个倾斜的大玻璃箱 | 真实的沃德箱（铁架、坡顶、银色框线），立在岛状花坛中央，箱内一簇发光晶体把它从里面照亮；倾斜来自相机的滚转 |
| 画面中心总是亮白、两侧却是黑色星空 | 室内由光之柱、三座晶心、星光玻璃拱顶照亮，四周侧墙是透明玻璃，看出去就是星空；同一个世界，从不同方向看得到两种背景 |
| 浅碗/玻璃球在窗前、又像在窗后 | 屏风后是整个中庭，屏风前的圆厅北侧另挂两串浅碗；前后层次都真实存在 |
| 蝴蝶、花瓣、光点飘在空中 | 用场景时钟驱动的粒子：蝴蝶沿四维噪声路径飞并扇翅，落花翻转飘落，光尘缓慢上升闪烁 |

## 3. 动态

所有运动都是场景时钟（Scene Time）的闭式函数，不需要烘焙，任意一帧都能直接渲染：

| 元素 | 运动 |
|------|------|
| 蝴蝶（`CF.FX.Butterflies`，192 只） | 四维噪声路径漫游，身体朝向飞行方向，翅膀每秒扇 4–4.5 次，随拍动上下起伏 |
| 光尘（`CF.FX.Motes`、光之柱内） | 缓慢上升、循环、随噪声漂移，逐个明灭 |
| 落花（`CF.FX.Petals`） | 螺旋翻转下落，出现时渐大、落地前渐隐 |
| 漂花（`CF.FX.Floaters`） | 池面上的山茶绕各自的位置缓慢打转 |
| 水面 | 倒影池的涟漪（每个 Voronoi 胞元一圈扩散的水纹，各自的生命周期） |
| 宝珠 | 里面的银河随时钟自转 |
| 吊饰 | 水晶吊坠、玻璃球、浅碗链以悬挂点为轴缓慢摆动（F 曲线噪声修改器） |

## 4. 灯光与外观

Cycles，Standard 视图变换（保留插画那样饱和的钴蓝与青色，高光自然溢出成白）。

* **光之柱**：玻璃管里是一根亮芯与一团按离轴距离高斯衰减的发光雾，管内三盏隐藏点光照亮整个圆厅。
* **星光玻璃**：中殿拱顶与圆厅穹顶是磨砂玻璃，自身微微发光——从下方照亮每条中殿，也让所有反射面（玻璃、水、抛光石地）
  映出明亮的天空；直接看它时发光收到 40%（相当于摄影的渐变滤镜），铁肋清晰可见。东廊用淡紫色。
* **晶心**：三条中殿尽端的巨型发光晶簇（内有隐藏点光），给每条长廊一个逆光的亮背景。
* **补光**：每条中殿拱顶下三盏隐藏面光，英雄机位背后各一盏大面积柔光（让罐子、浅碗正面也透亮）。
* **光雾**：整座温室充满很淡的前向散射雾（密度 0.003/m，各向异性 0.6），灯与亮背景自然晕开。
* **材质**：玻璃、水晶、水都是真实折射介质（阴影光线按颜色透过，温室不会被自身玻璃挡暗）；浅碗的水浓蓝，罐里的水青色带内发光；
  水晶带色散与薄膜干涉；银河宝珠是深钴蓝玻璃包着对数螺旋星系。
* **合成**：曝光 → 暗角 → 辉光 → 提升/伽马/增益 → 饱和度。每个英雄机位有自己的曝光，自由机位也可以（`views` 里的 `exposure`）。
