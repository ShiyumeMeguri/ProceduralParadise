# 惊鹿（鹿威し）

日本庭院里的竹筒：喷水棍往竹筒里注水，装到一定量竹筒失去平衡翻倒，水从斜切的筒口倒进石钵，
空筒弹回去敲在石头上"咚"一声，然后重新接水。

## 怎么玩

1. **按空格播放。** 模拟只在时间往前走时计算，第一次播到的帧要现算，算过的帧会缓存，再播就很快。
   时间线 1–1500 帧（约一分钟），默认设置下大约每 80 帧翻倒一次（装到约 120 mL）。
2. **开关水流**：`ShishiOdoshi` 修改器的 `Spray` 面板里勾掉 `Spraying` 就停水，再勾上又出水；
   播放中也能切，还可以给它打关键帧。`Liquid` 选择接下来喷的液体（水或黏液），已经喷出去的保持原样，两种液体会混在一起。
3. **移动喷水棍**：选中 `Wand`，按 G/R 移动、旋转，水柱跟着走（喷嘴在它的原点，沿自身 −Z 喷）。
   `Flow` 流量（mL/s）、`Nozzle Radius` 喷嘴半径（越小喷得越远）、`Spread` 散开角（0 是一股水，大了像花洒）。
4. **挡水的东西**：`Solids` 集合里的物体都会挡住水（石钵、喷水棍），把你自己的模型拖进这个集合即可，播放中移动也会推开水。
   `Table` 包围盒的顶面是无限大的地面；水流进空物体 `Drain` 的圆柱（半径 = X 缩放，高 = Z 缩放）就被排走，石钵不会溢出。
5. 想要稳定可重复或出最终渲染：修改器面板 → 模拟 → 烘焙。渲染器是 EEVEE（视图打开就是渲染着色）。

## 修改器参数

`ShishiOdoshi` 物体的原点就是转轴，X 轴沿着转轴，筒口朝 +Y。修改器（`Props.ShishiOdoshi.Simulation`）的面板：

* `Spray`：见上面「开关水流」。
* `Scene`：`Solids`、`Ground`、`Drain` 三个接口。
* `Tube`：竹筒尺寸——`Radius` 半径、`Wall` 壁厚（至少 1.5 个网格，否则水会渗过去）、`Front Length` 转轴到下唇尖、
  `Rear Length` 转轴到封口端（越长越能装）、`Septum` 隔节的位置、`Mouth Cut` 筒口斜切角；
  `Bamboo Density` 竹子密度、`Rest Angle` 靠在石头上时的角度、`Tip Angle` 翻倒的最低角度、
  `Rest Restitution`/`Tip Restitution` 两头的回弹、`Axle Damping` 转轴阻尼。
* `Stand`：立柱半径、石头的随机种子。
* `Look`：竹子、石头和两种液体的材质，以及每种液体的物性（密度、黏度、PIC 比例、固体摩擦、粘附、贴壁、屈服）。
* `Solver`：`Voxel` 网格边长（默认 4 mm）、`Particles Per Cell` 每格粒子数、`CFL` 每个子步粒子最多走几格、`Max Substeps` 子步上限。

修改器还输出几个数（可在属性里指定属性名查看）：`Angle` 竹筒角度、`Held Volume` 筒里的水（mL）、`Liquid Particles`/`Airborne Particles`
粒子数和在空中飞的粒子数、`Grid Substeps` 这一帧的子步数、`Pressure Residual`/`Pressure Iterations` 压力求解的残差与迭代次数。

## 速度

在 8 核 CPU 上，第一次模拟接水阶段约 150–500 ms 一帧，倒水阶段约 500–800 ms 一帧（倒水时水流快，子步多）；
算过的帧回放约 25 ms 一帧。要更快：

* `Voxel` 调到 5 mm：网格和粒子都少一半左右，约快一倍，细节粗一些；
* `CFL` 调大（例如 5）：子步更少，但水走得快的地方可能穿过竹壁，调大后留意筒外有没有漏水；
* 或者先烘焙，之后拖时间轴不再重算。

## 物理模型（节点组都能直接打开看）

* **竹筒**是绕转轴转动的刚体（`Physics.Hinge.Step`）：质量、质心和绕轴转动惯量按网格精确积分（每个三角形与原点构成的四面体），
  隔节后面封死的空腔让空筒的重心落在转轴后方，所以空筒口朝上靠在石头上。装在前腔（`Cavity`）里的水按粒子的真实位置
  加重力矩，并随竹筒一起转动（它的转动惯量并入竹筒）；水柱冲进筒里带进角动量，倒出去的水带走它那份。
  碰到石头或最低角时按回弹系数反弹，慢到两帧重力矩以内就停住，不会抖。
* **水**是网格 FLIP（`Physics.Fluid.Frame`）：交错 MAC 网格上做重力、黏性、固体面、带密度修正的散度，
  用预条件共轭梯度解泊松压力（空气处压力为零、固体处无穿透），投影后按 PIC/FLIP 混合插值回粒子，RK2 平流，再做碰撞、摩擦、粘附。
  子步数按 CFL 自适应；竹筒的位置在子步之间插值（位置线性、转动球面插值），转动的竹壁会推动筒里的水。
  离开固体两格以上、只受重力的水滴交给解析抛物线（`Physics.Fluid.Flight`），直到落进水里或撞上固体再回到网格。
* **固体**：竹筒是自己局部坐标里的有符号距离场，随变换移动；石钵、喷水棍、立柱和石头合成一个世界坐标的距离场，
  物体动了还带速度场。它们只在形状变化时重建（按几何指纹判断），不变就沿用上一帧的，这一项让每帧的固定开销从上百毫秒降到约 10 ms。
* **表面**：粒子 → 球并集距离场 → 平滑 → 等值面（`Physics.Fluid.Surface`）；视图里用模拟网格的分辨率，渲染时用 0.4 倍的细网格。
* **外观**（EEVEE）：水按 Beer–Lambert 吸收，厚度是每个顶点沿法线往里对自己打一条射线穿过去的距离（`Shading.Thickness`），
  同一个厚度也交给 EEVEE 的折射。
