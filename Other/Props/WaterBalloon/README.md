# 水气球

一只装满水的橡胶气球放在桌上，可以戳、可以托、可以拎着结甩。

## 怎么玩

1. **先按空格播放，再交互。** 模拟只在时间往前走时计算：暂停时拖动 `Stick`，气球不会有反应，看起来像直接穿过去了。
   时间线 1–3000 帧（约两分钟），播到头回到第 1 帧重新开始。
2. 播放中选中 `Stick`，按 G 拖着去戳（R 旋转）：橡胶凹下去，水把压力传到别处鼓起来，松开后整体晃动。
   戳得再快再深也戳不穿，气球会被推着走或者弹开。
3. `Colliders` 集合里的所有物体都会挡住气球：把手、杯子、你自己的模型拖进这个集合即可。
4. 勾选 `Balloon` 修改器上的 **Grab**：气球的结被空物体 `Hand` 拎起来；播放中移动、晃动 `Hand`，水气球跟着甩。
5. 渲染器是 EEVEE（视图打开就是渲染着色）。想要稳定可重复：修改器面板 → 模拟 → 烘焙，烘焙后拖动时间轴不再重算。

## 修改器参数

`Balloon` 物体上依次是三个修改器：

* **Shape**（`Props.Balloon.Shape`）：水滴形气球，`Radius` 半径、`Subdivisions` 细分、`Neck Height`/`Neck Radius` 扎口的形状。
  网格顶点上存着 `knot`（扎死的结）和 `neck`（扎口处没撑开的厚橡胶）两个属性；换成自己的网格时也要带上它们。
* **Simulation**（`Props.Balloon.Simulation`）：
  * `Pre-stretch` 充水撑开：越大橡胶绷得越紧、内压越高、晃得越快；
  * `Rubber Stiffness` 每条边的弹簧刚度 N/m（≈ 0.87 × 杨氏模量 × 厚度）；
  * `Slosh Damping` 晃动阻尼 1/s，越大晃得越少、滚动停得越快；
  * `Solver` 面板：`Substeps`（最少 8）、`Iterations`；快速戳击或更硬的橡胶可以加子步，3 次迭代时张力已收敛。
* **Subdivision**：平滑，视图里走 GPU 细分。

## 物理模型（节点组都能直接打开看）

* **橡胶膜**：Blender 5.3 原生 XPBD 求解器，每条边一个长度约束。静止长度 = 充水时长度 / 充水撑开，所以橡胶一直带着张力；
  扎口的 `neck` 不预拉伸、刚度 10 倍，`knot` 扎死了不受水压。开局内压就是与张力平衡的拉普拉斯压力
  （`Physics.Membrane.EquilibriumPressure`），气球一开始就处在平衡状态。
* **水**不单独模拟，而是：
  1. 不可压缩：每个子步末沿 ∇V = ΣAn/3 施加压力冲量，让体积变化率归零（冲量 / dt 就是内压的修正），再把残余漂移推回目标体积；
     被戳下去的体积一定从别处鼓出来；
  2. 有重量：水的势能 −ρg·∫x dV 对膜顶点求导得到静水压，重量经压力传到底部，放在桌上时底部压扁、侧面鼓出；
  3. 有惯性：水的质量按面积分到膜顶点；晃动阻尼只衰减相对质心的晃动与转动（里面的水几乎不随膜一起转）。
* **碰撞**：原生求解器只拿膜的顶点去碰碰撞体，细棍会从顶点之间挤过去；所以每个细分步再反过来，拿碰撞体的每个顶点去压膜的三角面
  （`Physics.Membrane.FaceContact`），同一顶点被几处推时满足最深的那一处。
* **一个子步**（`Physics.Membrane.Step`）：外力 → 细分 4 步 { 原生 XPBD 只解内部约束 → 角动量守恒投影 → 碰撞体顶点压面 → 解析地面 }
  → 从虚拟起点重新积分，原生 XPBD 只解钉住与碰撞体 → 地面 → 不可压缩体积。
  原生求解器每步把拉格朗日乘子清零、按颜色顺序投影，预拉伸橡胶会在刚体转动零空间里留下迭代消不掉的残余转动（气球会自己转、在桌上爬）；
  内部约束本不产生力矩，所以把角动量改回「起点值 + 外力的角冲量」。
* **外观**：气球是单层表面——水的折射界面加一层染色的橡胶涂层，撑得越薄越透（`stretch` 属性）。
  水的吸收按 Beer–Lambert：每个顶点沿法线往里对气球自己打一条射线，穿过去的距离就是厚度（`Shading.Thickness`），
  厚处颜色深、薄处透；同一个厚度也交给 EEVEE 的折射。
