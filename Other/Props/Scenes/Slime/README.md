# 史莱姆

一只果冻史莱姆，被木棍戳够次数就会死掉，黏液从伤口流出来，在桌上摊开。

## 怎么玩

1. 按空格播放。`Stick` 自带三次戳击：前两下从上面戳，史莱姆闪红、露出 > < 的吃痛表情、Q 弹地晃；
   第三下从侧面捅进去，生命归零，眼睛变成 X X，身体失去弹性，黏液从侧面的伤口涌出，顺着身体流到桌上摊开，
   史莱姆随着黏液流失越来越小、越来越扁。
2. 删掉 `Stick` 的关键帧，就可以自己拖着它（G 键）去戳。`Colliders` 集合里的所有物体都能碰到史莱姆。
3. 修改器面板里 `Health`、`Hit Force` 决定戳几下死、多大力才算一下；`Shape Frequency`、`Linear Deformation`、`Slosh Damping` 决定 Q 弹程度。
4. 想要稳定可重复或出最终渲染：修改器面板 → 模拟 → 烘焙。

## 修改器参数

`Slime` 物体上依次是三个修改器：

* **Shape**（`Props.Slime.Shape`）：水滴形身体，`Bottom Flatten`、`Peak`、`Bulge` 调形状；`Left Eye`、`Right Eye`、`Mouth`
  是五官在身体上的方向，网格上存成 `left_eye`、`right_eye`、`mouth` 三个属性，表情就贴在这三个顶点上随表皮运动。
* **Simulation**（`Props.Slime.Simulation`）：
  * `Life` 面板：`Health` 生命、`Hit Force` 受击力（N）、`Hit Cooldown` 吃痛表情持续时间；
  * `Jelly Body` 面板：`Shape Frequency` 果冻回弹（Hz，越高越硬）、`Linear Deformation`（0 = 目标只做刚体运动，1 = 允许整体保体积拉伸挤压）、
    `Skin Stiffness`、`Skin Pre-stretch`、`Compression Ratio`（薄皮受压就起皱，被戳凹的地方不会像硬壳一样撑着）；
  * `Wound and Goo` 面板：黏液的黏度、密度、PIC 比例、固体摩擦、粘附、贴壁、屈服强度，`Wound Radius` 伤口半径、
    `Softening Time` 死亡软化时间、`Remaining` 身体最少保留的体积比例、`Goo Voxel` 黏液的网格边长、
    `Goo CFL` 每个子步黏液粒子最多走几格（越小越稳、越慢）；
  * `Look` 面板：受击闪光、伤口、眨眼的节奏与各部分材质。
* **Subdivision**：平滑。

## 物理模型（节点组都能直接打开看）

* **身体**：和水气球同一套膜求解（`Physics.Membrane.Step`），多开了形状匹配（Müller 2005）：每个子步把身体按极分解
  拟合成「最佳刚体变换 + 一部分保体积的线性形变」的目标形状，膜顶点被弹性地拉向目标——所以它是果冻而不是水袋。
  目标按求解器的预测位置求；每个顶点的柔度 = 1/(质量 × ω²)，形状匹配不产生净力和净力矩。里面的黏液不可压缩、有重量。
* **受击判定**：膜求解输出这一帧碰撞体对表皮的冲量；冲量 / 帧时长 > `Hit Force` 且过了冷却，就扣一点生命，
  离冲量作用点最近的表皮顶点记为伤口。
* **死亡**：形状匹配的刚度按 e^(−t/τ) 衰减（τ = `Softening Time`）；表皮的静止边长以同一个时间常数蠕变到「当前边长 / 预拉伸」，
  皮跟着体积一起缩、一直保持一点张力，瘪下去是整个身体变小变扁，不会松成起皱折叠的软皮。
  伤口处的压力 p = 内压 + ρg·(形心高度 − 伤口高度) 推动黏液外流，流量按 Sampson 薄壁圆孔蠕动流 Q = r³·max(p, 0) / (3μ)。
  流出多少体积，身体的目标体积就减多少，同时在伤口外生成等体积的 FLIP 粒子；伤口压力降到 0 或身体只剩 `Remaining` 时停流。
* **黏液**：网格 FLIP（`Physics.Fluid.Step`）：交错 MAC 网格、泊松压力投影、PIC/FLIP 混合；黏性扩散一个子步把动量摊成方差 2ν·dt 的高斯，
  用盒式平均精确凑出（固体面当作幻影质量，贴壁无滑移）；屈服强度 = 贴着固体的底层宾汉塑性，所以黏液会拉丝、堆起、停在有限厚度。
  桌面、木棍、史莱姆的身体都是它的固体。
* **表面**：粒子 → 球并集距离场 → 平滑 → 等值面（`Physics.Fluid.Surface`）；视图里用黏液网格的分辨率，渲染时用一半边长的细网格。
* **外观**（EEVEE）：身体和黏液的绿色按 Beer–Lambert 吸收，厚度是每个顶点沿法线往里对自己打一条射线穿过去的距离（`Shading.Thickness`），
  厚处深、薄处透；同一个厚度也交给 EEVEE 的折射。
