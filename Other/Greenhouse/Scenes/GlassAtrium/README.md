# GlassAtrium：玻璃中庭温室（`Nitia` 机位）

参考画：`Reference/Nitia.webp`（2166 × 3000，原画）和 `Reference/Nitia_clean.webp`（去掉人物的版本，已按原画逐像素配准：
SIFT 特征 + 仿射，内点残差 1.0 px）。人物不在还原范围内，所有对比都对去人物版本做。
渲染：`Renders/Nitia.png`（原画机位，和原画同分辨率），`Renders/view_*.png`（自由机位）。

```bash
blender -b -P Other/build.py -- Greenhouse/Scenes/GlassAtrium                           # 构建并保存 Build/Greenhouse/GlassAtrium/GlassAtrium.blend
blender -b -P Other/build.py -- Greenhouse/Scenes/GlassAtrium --render nitia.png        # 原画机位
blender -b -P Other/build.py -- Greenhouse/Scenes/GlassAtrium --view overview --render overview.png
```

自由机位：`gallery`（画廊）、`garden`（从中庭地面往上看）、`stair`（楼梯平台）、`overview`（全景鸟瞰）、`table`（边桌特写）、
`plants`（画廊外沿俯看花园）。`.blend` 里整座建筑、花园和窗外的城市都在，任意换机位看到的是同一个世界。

全部几何都来自 `Greenhouse/Kit` 的几何节点资产，场景只是数据（`scene.json`、`data/planting.json`）。参考画只用来解相机、
量尺寸、拟合位姿和灯光，渲染时从不采样参考画，没有任何投影贴图。

## 1. 相机解算

原画是三点透视（俯视）。在原画上检测线段，按三个灭点分簇（竖直 228 段、沿画廊 121 段、横穿画廊 36 段），
用最小二乘同时解出焦距、主点和朝向（线段到灭点的角残差，按长度加权）：

| 参数 | 值 |
|------|----|
| 焦距 | 2798.3 px（36 mm 画幅宽度下 ≈ 46.5 mm） |
| 主点 | (710.4, 1001.7) px，偏左上 → 镜头移轴 |
| 朝向 | 偏航 23.53°，俯仰 −25.63°，滚转 −0.06° |
| 位置 | (0, 0, 2.5) m：画廊玻璃地面上方 2.5 m |

尺度：画廊外沿栏杆高 1.04 m，与相机高度 2.5 m 一起让每个物体都有合理的尺寸。
这次解算发现了 `Core/camera.py` 的一处错误：主点偏移原来按 `max(W, H)` 换算，竖幅画面会整体错位约 100 px；已改为按宽度换算。

## 2. 空间（原点 = 机位正下方的画廊地面，+Y 横穿画廊指向中庭，+X 沿画廊，Z 向上，单位米）

* **画廊**：玻璃地面（顶面 z = 0）铺在抛光玉石细梁上，楼梯井和外沿以北的中庭敞开。外沿是无框玻璃栏板，
  顶上两道横杆（0.91 / 1.04 m）之间一排短玉石立柱——原画只在两道横杆之间画了立柱。
* **立柱**：20 mm 玉石方柱，按原画里的竖线落位；原画只在画廊地面以下出现的几根止于地面下。
* **楼梯**：宽 1.5 m 的双跑楼梯，踏步 0.433 m、踢面 0.123 m；下跑 14 级到 z = −1.354 的平台，上跑 11 级转向西翼。
  踏步位置由原画的踏步前沿线联合拟合（残差 16 px rms）。每级是厚等于踢面高的实心石阶，级与级之间封闭——原画的踏步
  一级紧接一级，从上面看不到踏步缝里的花园。
* **中庭花园**：`calibration/planting_plan.py` 把花园地面分成 0.5 m 的格子，先把格子自己的土面、再把其上 0.3–2.6 m 的
  高度点投回原画：原画在那里画着植物，就允许种到那么高（地被 / 林下 / 灌木三档）；看到的是浅色地面就铺石板（格子上方的点
  投得更高，可能落在后面的植物上，所以只有土面本身能说明这格是不是铺地；地面上橙黄的光斑色相低于叶子，不算植物）；只隔着
  玻璃器皿看得到的格子取邻格的档；机位看不到的格子按设计种满，只留出楼梯脚、北墙前的铺装庭院和园桌下的地面。主景植物
  （`Painted ...`）各放在原画里那团植物中心像素按树冠高度反投影到的位置，树冠大小按原画那团的范围。
* **屋顶藤蔓**：藤蔓沿屋顶框架攀爬，离画廊地面 6.3–6.6 m，高于原画机位的所有视线——原画里看不到它，只看得到它投下的
  斑驳日影：庭院、踏步、画廊地面上叶形的光斑，和叶隙间的光柱。北侧看不见的角落另有三棵伞树。
* **画廊陈设**：每件都按原画拟合位姿——高玻璃方瓶（12 mm 厚壁、4 cm 厚底的绿玻璃空瓶——厚壁侧看是深绿的边、
  厚底是一块深绿的瓶脚，正看清透，和原画一样；瓶肩是穹顶：直立的瓶壁以四分之一椭圆收成平顶，接上短粗的瓶颈）、扁球烧瓶（原画画成扁的，用 `Squash` 做成
  扁球体）、边桌，桌上的手机、玻璃块、玻璃球、花插按原画的角点最小二乘解出位置与朝向；栏杆内侧一盆双干散尾葵，叶子只朝
  背离机位的那一侧伸展（原画里看不到伸向机位的叶子，它下面是一片深暗的花园）。
* **吊球**：四个开口玻璃吊球，每个球的中心和半径由原画的圆轮廓反投影解出，开口朝向机位；球底铺满白石子（石子数按
  石床面积算，铺满为止），石床是内球面在填充高度处切下的球冠，不会穿出玻璃。
* **外壳与窗外**：四面幕墙（北墙是结构胶玻璃，只有横档）和 2 m 网格玻璃屋顶。温室在 117 m 高的塔楼顶上：
  画面最上一行也在地平线以下 6°，所以窗外的粉白是阳光下的城市烟霭，不是天空。塔北侧 16 m 以下是裙楼屋顶花园，
  那些树冠按原画树冠轮廓的顶点定位（30–45 m 外）；裙楼只伸出 33 m，刚好在它的屋面升到"穿过北墙墙脚的视线"之上以前
  收住，所以屋面从来看不到，再往外视线直接落进烟霭。更远 84 m 处一栋矮楼屋顶上有一棵远树（冠宽 6.3 m，按原画那团淡影
  定大小），那栋楼同样收在视线以下；左上方是邻楼。城市烟霭是包住温室的体积（温室内部挖空），只作背景（见第 4 节），室内另有一层均匀散射的湿润薄光雾。
  城市地面和烟霭都铺到 6 km 外：画面最上一行向下 6°，视线要到 1.2 km 外才落地——地面若在 900 m 处收边，边缘会在烟霭里
  显出一道横线。

## 3. 原画中"反 3D"的结构与处理

原则：**3D 里是合理、可以自由换机位的建筑；在原画机位下尽量贴合原画**，不为了贴合去扭曲几何。

| 原画现象 | 处理 |
|----------|------|
| 边桌桌面椭圆比该处水平圆盘能投影出的更圆（纵横比 0.57，而这条视线上任何水平圆盘最多 0.44） | 圆盘匹配原画的宽度和中心，桌上物件按原画角点定位 |
| 烧瓶画得比球扁 | 做成扁球体烧瓶（`Squash` 0.665），轮廓按原画椭圆拟合 |
| 楼梯前沿只收敛到竖直灭点，踏步比普通楼梯宽而浅 | 宽 1.5 m、踏步 0.433 m 的景观楼梯，加平台和转向西翼的上跑，楼梯有出发点也有去处 |
| 窗外树冠贴着玻璃，却看不到树干和地面 | 树种在低 16 m 的裙楼屋顶，树冠顶点按原画轮廓，树干和屋面落在所有穿过幕墙的视线以下 |
| 窗外远处除了烟霭和一棵淡淡的远树，什么屋面都没有 | 每一片屋面都在它升到"穿过北墙墙脚的视线"之上以前收住 |
| 庭院、踏步、画廊地面上处处是叶形的斑驳日影，头顶却看不到任何遮挡 | 屋顶框架上的藤蔓——在原画机位所有视线之上，只露出它的影子 |
| 立柱成对出现、间距不均 | 按原画位置保留：结构柱加栏杆立柱，两套构件并排 |
| 去人物参考画里没有原画中的椅子 | 不做椅子 |

## 4. 外观

Cycles，Standard 视图变换，合成器里一道按原画拟合的调色（见第 5 节）和一层柔光。

原画最好看的是玻璃：层层叠叠的反射、翡翠色的玻璃边、剔透的器皿。所以温室里每一种玻璃都是设计系统
（`Greenhouse.json` 的 `glasses`）里的一行数据——折射率、阿贝数（色散）、比尔–朗伯吸收的颜色与密度、壁厚——由同一个
构建函数（`Kit/materials.py` 的 `dielectric`）做成 Cycles 的 Principled BSDF 全透射电介质；5.3 新加的透射色散只开在
厚而弯的器皿上（平行的板子色散互相抵消，只会多出噪点）：

| 玻璃 | 用在 | 折射率 | 阿贝数 | 着色 |
|------|------|--------|--------|------|
| `GH.Glass` | 幕墙、屋顶 | 1.52（浮法玻璃，不镀膜） | — | 含铁的淡翠，只在板边深 |
| `GH.GlassCoated` | 玻璃地面（40 mm 夹层） | 1.22（减反射膜的等效值） | — | 同上 |
| `GH.GlassReflective` | 栏板（21.5 mm 夹层） | 2.0（金属氧化物反射膜的等效值） | — | 同上 |
| `GH.Jade` | 框架：梁、立柱、横档、扶手、桌腿 | 1.56 | — | 浇铸的翡翠玻璃，2 cm 的杆透过来是深翠 |
| `GH.GlassJade` | 玻璃家具：边桌面、园桌、楼梯玻璃梁 | 1.6（晶质玻璃） | 35 | 翡翠 |
| `GH.GlassLustre` | 烧瓶、玻璃球 | 1.6，反射 ×12（见下） | 35 | 翡翠 |
| `GH.GlassClear` | 吊球、玻璃块 | 1.6 | 35 | 几乎无色，只在球沿泛翠 |
| `GH.GlassBottle` | 高方瓶 | 1.52 | — | 黄绿的瓶绿 |
| `GH.Water` | 烧瓶里的水 | 1.333 | — | 深翠 |

* **翡翠框架**：原画的梁柱不是不透明的石头——放大看，杆子后面的花园透过来，染成绿色，一侧有一道亮边。所以框架是
  浇铸的翡翠玻璃（全玻璃结构的玻璃梁、玻璃肋是真实的建筑做法）：一根杆是它后面的房间透过来染成深翠，边缘因全反射发暗，
  迎光的一面亮。
* **建筑玻璃**：幕墙和屋顶是不镀膜的浮法玻璃，正看约 4% 反射、掠射时变成镜面，把框架、吊球、粉色的墙叠进透过来的景物里；
  栏板镀反射膜，每块栏板都在透过去的景物上叠一层淡淡的房间倒影——原画里一层叠一层的反射就是这样来的。脚下的玻璃地面
  镀减反射膜，透下去的花园不被整个温室的倒影蒙上一层白。无框处玻璃板对接，板边在墨线里是安静的——拼缝不是一条画线。
* **器皿的光泽（反射探针）**：原画的烧瓶、玻璃球上是一块块粉白的窗格倒影，压在清透的瓶身上。真实的房间从球面看
  四面八方都亮，照实反射只是一层均匀的白雾；所以带光泽釉（`GH.GlassLustre`）的器皿多反射 11 倍于自身反射率的
  "房间"（不超过镜面），房间是一个闭式的反射探针（`Greenhouse.json` 的 `reflection_room`，即游戏引擎里的 cubemap）：
  按反射方向的方位角分 8 个开间、按仰角分三排窗（−16°–4°–22°–40°，正是从烧瓶处看幕墙的上下范围），窗格里是烟霭的粉白，
  竖梃、横档、一半被藤蔓和树挡住的窗格（逐格随机）、花园和屋顶都不加光——倒影只会提亮，瓶身照样透明。探针只依赖反射方向，
  换机位照样成立。平面的高方瓶不加：它的竖直面反射的是下方的花园，原画里也是清透的。
* **薄玻璃里的光**：光在吊球的 3 mm 薄壁、玻璃板边里靠全反射传导，Cycles 把每次全反射都算作一次高光反弹；默认 4 次
  高光反弹会把这些路径截断，开口的边缘渲成一圈黑。反弹上限因此是镜头数据（`render.cycles`），本镜头高光与透射各 64 次，
  开口边缘才是原画里那一圈淡青的亮边。
* **光穿过玻璃**：玻璃对相机光线和镜面反射光线是真实电介质；对阴影光线和漫反射光线是带色透明（菲涅尔损失 × 半壁厚的
  比尔–朗伯透射）——折射后的光本来是焦散路径，渲染器不追踪，否则阳光和天光都进不了温室。
* **墨线**：原画是勾线的。另开一个视图层，用对象随机值 + 元素编号着色，在合成器里对身份色和法线做 Sobel 得到轮廓与折线；
  玻璃标记为可透视（只在掠射的边缘出线），植物和铺装标记为安静（不出线，并挖掉背后的线）。线宽按画面算：Sobel 在任何
  分辨率下都画两个像素宽，合成器在渲染时读出图像的实际尺寸，小于原画尺寸时按线覆盖的比例减淡——四分之一尺寸的搜索小图
  和全尺寸成图的墨线在画面上一样粗细（此前小图的线相当于粗了四倍，所有按小图做的取舍都偏向遮住结构线）。
* **城市烟霭**：`GH.Smog` 用空气透视的闭式解：吸收介质 + 按密度发光。烟霭包住温室，所以透过每一块玻璃看到的、
  每块玻璃和器皿映出的都是它；但它只作背景，不照亮室内的表面（对漫反射光线不可见）。此前它的粉光当环境光，从四面八方
  照进来：阴影里的叶子 42% 的光来自它，亮暗只差 3 倍，整座花园一片灰平；原画的阴影深、日照处亮，差近 10 倍。漫射的
  天光本来就由天空（`sky.sun_ratio`）代表，烟霭再照一遍是重复计算。去掉以后，植物的亮度分布（10/25/50/75/90% 分位）
  从 34/44/53/68/76 拉开到原画的范围，L > 70 的日照叶子从 6% 回到原画的 27% 附近。
* **日光**：太阳按真实大小（0.53°），九米高的藤蔓投下的光斑边缘清晰。阳光穿过城市烟霭，蓝光被散射掉，是金黄的
  (1.0, 0.85, 0.32)——原画里淡粉地面上的光斑是橙黄的，不是粉白。铺地是淡紫粉色的石材。

## 5. 灯光标定（`calibration/fit_lights.py`）

光照对光源强度是线性的：日光（太阳灯 + 天空，天光是被空气散射的阳光，两者保持场景给定的比例
`sky.sun_ratio` = 0.26——雾天水平面上约 40% 的光来自天空）、城市烟霭各放进一个 Cycles light group，一次渲染得到每组的
线性图像，再只解每组的强度（颜色留给材质）。目标 = 1/60 画宽高斯模糊后的显示值误差 + 画面五条横带各自的 CIELAB 分位数误差
（每条带的暗部、中间调、高光和它们的色相），Powell 多起点求最低的谷。天空若不和太阳绑定，会被拟合得比任何天空都亮，
每块玻璃都会映出一层乳白。

```bash
blender -b -P Other/Greenhouse/Scenes/GlassAtrium/calibration/fit_lights.py -- groups.npz --samples 48 --scale 0.25
python Other/Greenhouse/Scenes/GlassAtrium/calibration/fit_lights.py groups.npz --apply
```

**调色**（`calibration/fit_grade.py`，灯光之后）：原画的阴影是深青、绿叶饱满、高光粉亮；只拟合光强的渲染在这些地方是灰平的。
**叶色**（`calibration/fit_foliage.py`，和灯光交替两轮，再调色）：每株植物（主景植物、种植层的每个原型、窗外的树）
在原画机位下的像素由一张对象编号图取出，按亮度中位数分成背光、受光两半，各取原画与渲染（不带观感，和灯光拟合看的同一张）
的线性中位色；两半之比的几何平均（八成，每轮至多两倍）按通道乘到这株植物的两种叶色上，再缩回原来的亮度——只拟合色相和
饱和度。原画的叶子和渲染的叶子不会一片片对齐，渲染里一株植物的轮廓内，原画画的是它和邻株的混合，亮度会往整座花园的平均
回归：连亮度一起拟合，向阳的散尾葵被压暗、背阴的龟背竹被提亮，亮暗分布从 34/44/53/68/76 塌成 37/45/53/61/67。亮度交给
灯光。

```bash
blender -b -P Other/Greenhouse/Scenes/GlassAtrium/calibration/fit_foliage.py -- foliage_dir --samples 48 --scale 0.25
python Other/Greenhouse/Scenes/GlassAtrium/calibration/fit_foliage.py foliage_dir --write
```

调色是三条逐通道的色调曲线，把"带着镜头观感（墨线、柔光）但不带调色"（`--no-grade`）的渲染的直方图对到去人物原画的直方图。
整条对上会在叶子、光斑没对齐的地方放大误差，所以曲线从恒等往拟合结果走一个比例，比例在 0–1 之间按灯光拟合的同一个目标
（模糊色调误差 + 分带分位数，`fit_lights.Target`）取最低——本镜头取 0.60。

```bash
blender -b -P Other/Greenhouse/Scenes/GlassAtrium/calibration/fit_grade.py -- ungraded.png --samples 48 --scale 0.25
python Other/Greenhouse/Scenes/GlassAtrium/calibration/fit_grade.py ungraded.png --write
```

原画是暖光照亮处偏黄、阴影偏青的画法。下面这些想把渲染往那边推的物理改动，都和各自的基线成对比较过（四分之一尺寸，
色调误差的增量；动了光的都重新拟合过灯光），全部更差：屋顶换成吸热的玉色玻璃（阳光和天光都偏青）+0.0024、藤蔓加倍
让光柱成形 +0.0026、室内光雾加浓到 0.04（只成了一层灰纱，没有光柱）+0.044、建筑玻璃着色加深四倍 +0.0049、
烟霭标高降到 40 m（天顶变蓝）+0.0005、窗外树改偏绿的叶色 +0.0005。上界检验：直接在成图上把日照处调暖、阴影处调青，
最优的一组也不降低色调误差——剩下的误差在空间上（哪里是叶团、哪里是铺地、哪里落着光斑），不在配色上。

色调误差偏爱平光：叶子、光斑和原画对不齐的地方，最省误差的是灰平的中间调，所以只看它会把画面拉平。不镀膜的建筑玻璃、
镀反射膜的栏板和翡翠玻璃框架加起来只多 +0.0013，换来原画的反射层次，值得；调色（第 5 节）则按灯光拟合的目标来取舍。

**布局**（`calibration/layout_search.py`，最后一步）：种植层把植物撒在哪、每株主景植物怎么长叶子，都是随机的——同样合理的
花园有无数个；主景植物站在哪、长多大只知道到原画那团植物的宽度，朝向则完全不知道；太阳的方位只知道到光柱和日影给出的
几度。所以这些都按原画挑：逐个对象把一个字段（`seed` 种子、`move` 位置前后左右挪、`turn` 朝向转 45° 的倍数、`size`
放大缩小一成、`aim` 灯的方位角和高度角各转几度、`input` 任一数值输入如小叶宽、复叶数放大缩小一个比例）换成另外几个值，
每个值渲一张原画机位的小图，留下让整张图最接近原画的那个（模糊色调误差 + 四分之一逐像素误差，也就是报告的指标本身）。
太阳就是这样从方位角 30° 挪到 31°。只按整张图挑是有意的：
同一种植配比换七个种子，色调误差就在 0.091–0.098 之间跳；若按画面分块各挑各的（例如每块挑最像的物种），这种噪声
会被当成收益挑出来——六个随机种子逐块取最优就能"降到" 0.083，和六个物种逐块取最优（0.081）几乎一样，真正归于物种的
只有零头。按原画拟合过位置的画廊陈设（方瓶、烧瓶、边桌和桌上物件）不参与挪动。

blender -b -P Other/Greenhouse/Scenes/GlassAtrium/calibration/layout_search.py -- "Ground Painted,Areca Palm,Roof Vines" --field seed --tries 6
blender -b -P Other/Greenhouse/Scenes/GlassAtrium/calibration/layout_search.py -- "Painted Banana,Painted Dracaena" --field move --step 0.2
