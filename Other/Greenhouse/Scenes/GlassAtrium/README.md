# GlassAtrium：玻璃中庭温室（`Nitia` 机位）

参考画：`Reference/Nitia.webp`（2166 × 3000，原画）和 `Reference/Nitia_clean.webp`（去掉人物的版本，已按原画逐像素配准：
SIFT 特征 + 仿射，内点残差 1.0 px）。人物不在还原范围内。
渲染：`Renders/Nitia.png`（原画机位，和原画同分辨率），`Renders/view_*.png`（自由机位）。

```bash
blender -b -P Other/build.py -- Greenhouse/Scenes/GlassAtrium                           # 构建并保存 Build/Greenhouse/GlassAtrium/GlassAtrium.blend
blender -b -P Other/build.py -- Greenhouse/Scenes/GlassAtrium --render nitia.png        # 原画机位
blender -b -P Other/build.py -- Greenhouse/Scenes/GlassAtrium --view overview --render overview.png
```

自由机位：`gallery`（画廊）、`garden`（从中庭地面往上看）、`stair`（楼梯平台）、`overview`（全景鸟瞰）、`table`（边桌特写）。
`.blend` 里整座建筑都在，任意换机位看到的是同一个世界。

全部几何都来自 `Greenhouse/Kit` 的几何节点资产，场景只是数据（`scene.json`）。参考画只用来解相机、量尺寸、拟合颜色，
渲染时从不采样参考画，没有任何投影贴图。

## 1. 相机解算

原画是三点透视（俯视）。在原画上检测线段，按三个灭点分簇（竖直 228 段、沿画廊 121 段、横穿画廊 36 段），
用最小二乘同时解出焦距、主点和朝向（线段到灭点的角残差，按长度加权）：

| 参数 | 值 |
|------|----|
| 焦距 | 2798.3 px（36 mm 画幅宽度下 ≈ 46.5 mm） |
| 主点 | (710.4, 1001.7) px，偏左上 → 镜头移轴 |
| 朝向 | 偏航 23.53°，俯仰 −25.63°，滚转 −0.06° |
| 位置 | (0, 0, 2.5) m：画廊玻璃地面上方 2.5 m |

尺度：画廊外沿栏杆高 1.04 m、立柱间距 1.42 m，与相机高度 2.5 m 一起让每个物体都有合理的尺寸
（吊球半径 0.12–0.20 m，高玻璃瓶 1.8 m，边桌 0.6 m 高）。

这次解算发现了 `Core/camera.py` 的一处错误：主点偏移原来按 `max(W, H)` 换算，而相机的传感器按水平方向适配，
竖幅画面会整体错位约 100 px；已改为按宽度换算（横幅场景不受影响）。

## 2. 空间（`scene.json`，原点 = 机位正下方的画廊地面，+Y 横穿画廊指向中庭，+X 沿画廊，Z 向上，单位米）

* **画廊**：玻璃地面（顶面 z = 0）铺在 30 × 80 mm 的绿色钢梁上，外沿一排磨砂玻璃；外沿在 y = 4.18，1.04 m 栏杆
  （五道横杆 + 玻璃栏板），栏杆在 x = −2.16 转角折回。
* **立柱**：30 mm 方钢，从中庭地面（z = −3.2）直通屋顶（z = 7.22）。每一根都按原画里的竖线落位。
* **西侧楼梯**：宽 1.5 m 的双跑楼梯，踏步 0.433 m、踢面 0.123 m；下跑 14 级从中庭地面到 z = −1.35 的平台，
  上跑 11 级转向西，到达西翼画廊。踏步位置由原画里的 6 条踏步前沿线联合拟合（残差 16 px rms）。
* **中庭花园**：地面铺石板，楼梯两侧、画廊下、东侧各有种植池；鹅掌柴、龟背竹、海芋、芭蕉、散尾葵、肾蕨、
  吊兰、龙血树，外加按密度随机散布的灌木和地被（`GH.Garden.Planting`，原型在不渲染的 `library` 集合里）。
* **画廊陈设**：高玻璃方瓶（空心，1.8 m）、圆底烧瓶、高脚玻璃椅；外沿的边桌上有黄铜花插、玻璃块、玻璃球和一本书；
  栏杆内侧种着一盆散尾葵。
* **吊球**：四个开口玻璃吊球，里面是白石子和多肉（芦荟、石莲、小灌木），开口朝向机位，从屋顶用细线吊下。
  每个球的中心和半径都由原画里的圆轮廓反投影解出。
* **外壳**：四面幕墙（2 m 竖梃、3.9 m 横档）和 2 m 网格的玻璃屋顶。温室坐落在两层高的玻璃裙楼上，
  窗外是比中庭地面低 8.8 m 的草坪和行道树，远处是城市塔楼；整个空间充满一层薄薄的光雾，窗外的雾更浓。

## 3. 原画中"反 3D"的结构与处理

原则：**3D 里是合理、可以自由换机位的建筑；在原画机位下尽量贴合原画**，不为了贴合去扭曲几何。

| 原画现象 | 处理 |
|----------|------|
| 楼梯的踏步前沿只收敛到竖直灭点，看不出上下关系；踏步明显比普通楼梯宽而浅 | 做成宽 1.5 m、踏步 0.433 m / 踢面 0.123 m 的景观楼梯（逐级拟合原画前沿线），再加平台和转向西翼的上跑，楼梯有出发点也有去处 |
| 椅子腿画得前后矛盾：一根斜伸到座面中心，一根竖直落地 | 做成一把合理的高脚玻璃椅，四条外撇的腿落在原画里的四个脚点上 |
| 窗外的树冠几乎贴着玻璃，树干却看不到根部 | 温室放在裙楼顶上，行道树种在 8.8 m 下方的街面，树冠正好长到窗外 |
| 中庭里的植物都在玻璃地面正下方很近的位置 | 中庭层高取 3.2 m（不是更常见的 4.5 m），种植池高出地面，植物冠层就在玻璃下方 |
| 画廊外沿的一排地面比其他玻璃白 | 外沿一排是磨砂玻璃 |
| 立柱在外沿成对出现、间距不均（0.19 / 0.23 / 0.56 m） | 按原画位置保留：结构柱加栏杆立柱，两套构件并排 |

## 4. 外观

Cycles，Standard 视图变换。材质都是程序化的：建筑玻璃是带绿色吸收的真实电介质（侧看是深青色、正看几乎透明），
阴影光线用带色透明，这样阳光能穿过玻璃地面照进花园；玻璃器皿有体积吸收；叶片按每片叶子自己的 `leaf_color`
着色，带中脉暗化、蜡质高光和透光；光雾是前向散射的体积。

`calibration/fit_grade.py`：用未调色的渲染与去人物参考画做直方图匹配，拟合出按显示值的逐通道色调曲线，
写入 `shots/Nitia.json` 的 `look.grade`。直方图匹配不会像逐像素回归那样把对比度压平。

```bash
blender -b -P Other/build.py -- Greenhouse/Scenes/GlassAtrium --no-save --no-look --render ungraded.png
blender -b -P Other/Greenhouse/Scenes/GlassAtrium/calibration/fit_grade.py -- ungraded.png --write
```
