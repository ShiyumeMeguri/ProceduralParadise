# TeaHouse — 山海经高级中学 茶楼（`BG_ShanTeaHouse_Night`）

参考原画：`Reference/BG_ShanTeaHouse_Night.webp`（1280 × 900）。
渲染结果：`Renders/BG_ShanTeaHouse_Night.png`（原画机位），`Renders/BG_ShanTeaHouse_Night_compare.png`（左渲染 / 右原画），
`Renders/view_*.png`（自由机位验证），`Renders/metrics.json`（数值对比）。

完整场景不进仓库，由脚本生成（Blender 4.4 以上，界面里 Run Script 或命令行均可，见仓库根目录 README）：

```bash
blender -b -P BlueArchive/build.py -- Shanhaijing/Rooms/TeaHouse                          # 构建并保存 Build/Shanhaijing/TeaHouse/TeaHouse.blend
blender -b -P BlueArchive/build.py -- Shanhaijing/Rooms/TeaHouse --render out.png         # 原画机位
blender -b -P BlueArchive/build.py -- Shanhaijing/Rooms/TeaHouse --view reverse --render reverse.png
blender -b -P BlueArchive/build.py -- Shanhaijing/Rooms/TeaHouse --render-animation       # 配布视频
```

全部几何都来自 `Shanhaijing/Kit` 里的几何节点资产（39 个 GN 资产、64 个程序化材质），房间只是数据（`room.json`）；
参考图只用来标定相机、测量尺寸和拟合灯光/颜色，渲染时从不采样参考图，没有任何投影贴图。

## 1. 相机解算

原画是两点透视（竖线全部竖直，俯仰 = 滚转 = 0）。对梁、地砖缝、墙板等线段做检测，按房间两个水平轴分簇拟合灭点：
x = 2646.5 px 与 x = 253.1 px，同在地平线 y = 498.25 px 上。主点横坐标取画面中心，两灭点方向正交给出焦距
f² = (2646.5 − 640)(640 − 253.1)。

| 参数 | 值 |
|------|----|
| 焦距 | 881.1 px（36 mm 画幅宽度下 ≈ 24.8 mm） |
| 主点 | (640, 498.25) px → 无主点偏移 |
| 朝向 | 偏航 −23.71°（看向 +Y，偏向右侧柱廊），俯仰 0，滚转 0 |
| 位置（房间坐标） | (2.0, 3.0, 1.0) m |

尺度由家具定标：茶桌 1.02 m 见方、高 0.754 m，地砖木纹板 1.4 × 0.33 m（错缝 0.37）——用多张桌子的桌角/桌腿
反投影联合拟合（网格搜索，特征点残差约 2 px），相机高度 1.0 m 与所有桌子、椅子一致。

## 2. 房间（`room.json`，房间坐标：原点 = 左墙内表面 × 前墙，+X 横穿大厅，+Y 向里，Z 向上）

* 19.3 × 22.3 m。主厅 X 0–9.65 m，柱廊（X = 9.65，红色柱套的立柱、黑漆金纹额枋、雀替）右侧是侧厅；后墙在 Y = 22.3。
* 顶棚：前部白色平顶 5.9 m（Y 0–14.95），后部木板吊顶 5.6 m（封檐板后面），全部木梁底 5.27 m，
  木梁交点处的吊柱（垂柱）带圆盘；侧厅是 5.3 m 的较低木板吊顶。
* 后墙：宽 5.85 m、高 3.82 m 的博古架，中间钥匙孔形月洞门（半径 0.96 m），每一层板、隔板、托角都由原画反投影测得
  （`Kit/data/bogu_shelf.json`）；两侧三块米色墙板上的圆窗是原画的八方海棠花格（四个正八边形 + 海棠花心 +
  双十字中轴 + 端部 Y 形撑，按原画描线），磨砂玻璃后面是庭院灯；左侧壁龛是蓝色方格大窗。
* 斜置的 Logo 墙（与柱廊方向成 16°，面向主厅）：校徽由原画在墙面矫正平面上矢量化（`Kit/data/shanhaijing_emblem.json`，
  外圈 221 点 + 27 个字形轮廓），两侧是蓝色行草字列的漆板，前面一对石狮。
* 家具：9 张茶桌（标准 1.02 m 见方、0.754 m 高；左后两张是 0.66 m 高的矮桌，其中一张 1.25 m 见方；中间一张 1.65 × 1.0 m 长桌）、17 把灯挂椅
  （铜钉、红色坐垫金色滚边），每把椅子相对自己的桌子定位，全部面向桌子；桌上是锤纹铜壶、托盘、点心碟。
* 左墙：7.2 m 玻璃茶叶柜（回纹金边，红色茶盒、茶罐、小白盒，柜顶蓝色礼盒、青花瓶里的高草、菜单平板）。
* 灯：4 串红灯笼（圆形灯身、金色福字、小顶盖、下方金色短筒，内置暖色点光）；木梁底面的筒灯；
  平顶里的隐藏筒灯（只照明，不可见）；庭院灯、柜内灯、Logo 墙洗墙灯与若干隐藏补光。

## 3. 原画中的"反 3D"结构与处理

原则：**3D 里是合理、可自由换机位的建筑；在原画机位下尽量贴合原画**，不为了贴合而扭曲几何。

| 原画现象 | 处理 |
|----------|------|
| Logo 墙的上下沿与竖边不收敛到房间的任何一个灭点 | 做成真实的斜墙（−73.99°），位置与角度由上沿、下沿、左右竖边 4 条线索联合拟合 |
| 木板吊顶画成竖直条纹（平顶上的线不可能在画面里竖直） | 平顶木板沿进深方向铺设，逐板色差、弱化板缝——保留深色条纹感，但几何合理 |
| 前排木梁上的吊柱间距不均（X 1.85 / 4.7 / 5.4 / 7.97 / 9.65 m） | 按原画位置保留（木构中可接受），不在梁交点处的两根不带圆盘 |
| 左后两张桌子比前排的大而矮 | 两种桌型：1.25 m 见方 / 0.66 m 高的矮方桌，与标准茶桌并存 |
| 右侧灯笼串低到额枋前方 | 灯串悬挂在 5.9 m 平顶，位置在额枋前（X 9.3, Y 8.2），垂到约 1.9 m |
| 圆窗里的暖色光斑 | 窗外庭院里放真实的庭院灯（灯柱 + 发光球），透过磨砂玻璃呈柔和光斑；任何机位都成立 |
| 平顶上看不到灯具，地面与家具却有明显顶光 | 平顶里的隐藏筒灯（不可见、只照明），按原画亮度分区（前 / 中 / 后排、侧厅）拟合 |
| 侧厅顶棚比主厅低且更亮 | 侧厅用 5.3 m 的浅色木板吊顶和自己的筒灯 |

## 4. 灯光与外观（渲染 → 合成）

Cycles，Standard 视图变换。灯光是按原画"解"出来的，而不是目测调的：

1. `calibration/fit_lights.py`：每一类灯（筒灯各分区、灯笼、隐藏洗墙灯、补光、庭院灯、发光材质……共 31 组）
   放进各自的 Cycles light group，一次渲染得到每组的线性图像；光照对强度是线性的，于是在
   **显示空间**（sRGB 编码、白点截断之后）对原画做鲁棒误差最小化，解出每组的权重（L-BFGS，对数权重，弱先验）；
   `--apply` 把权重乘进 `room.json` 的灯功率和镜头里的发光参数。
2. `calibration/fit_grade.py`：在未调色的渲染与原画之间，用语义区域 + 网格的区域均值拟合全局调色
   （3 × 3 颜色矩阵 + 单调曲线），写入 `shots/BG_ShanTeaHouse_Night.json` 的 `look.grade`；
   超出 [0, 1] 的高光先按最大通道向白色压缩（`highlight_rolloff`），红灯笼不会被曲线外推成粉色。
3. 合成器：曝光 → 调色 → 辉光。调色是全局的，换机位同样适用。

几何对位用 `calibration/overlay.py`（模型轮廓红线叠到原画边缘青线上）逐区域检查。

## 5. 验证（与原画逐像素对比，sRGB 0–1）

最终渲染 `Renders/BG_ShanTeaHouse_Night.png`（128 spp，调色 + 辉光）对原画：

| 指标 | 数值 |
|------|------|
| 全图平均绝对误差 MAE | 0.0969（约 25/255） |
| SSIM（亮度结构相似度） | 0.399 |
| 边缘召回（2 px 内） | 0.576 |
| 29 个语义区域平均色差 | 0.0463 |
| 亮度分位 5/25/50/75/95 %（渲染） | 0.121, 0.182, 0.327, 0.429, 0.597 |
| 亮度分位 5/25/50/75/95 %（原画） | 0.091, 0.182, 0.320, 0.457, 0.599 |

区域色差最大的四处：back_panel_M 0.127（中间圆窗左侧墙板，原画被窗后灯光照成偏绿的亮色）；
chair_back 0.123（原画这里的椅背后面露出地面反光）；counter 0.089（茶叶柜玻璃里的货品）；plaster_centre 0.079。

剩余误差主要来自笔触层面：原画的地面反光、木纹与灯光光晕是手绘的，渲染是物理的；几何与整体色调已对齐。
完整区域表见 `Renders/metrics.json`，可用 `verify.py` 复算。

## 7. 配布视频（`animations/Showcase.json`）

`CAM_Showcase`：1920×1080、30 fps、840 帧（28 秒），构建后就是场景的活动相机；渲染方法同 ClubRoom
（Ctrl+F12 逐帧渲染 PNG 序列、可断点续渲，`Showcase Video` 场景合成 MP4；或命令行 `--render-animation`）。

| 帧 | 镜头 |
|----|------|
| 1–50 | 与原画完全相同的机位停留 |
| 50–190 | 右移进入左、中两列桌子之间的过道，沿过道推进 |
| 190–300 | 推到博古架与月洞门前 |
| 300–420 | 左转看玻璃茶叶柜与灯笼串 |
| 420–540 | 退回过道，转向柱廊 |
| 540–660 | 穿过桌间，停在两只石狮之间的校徽前 |
| 660–840 | 升到前右方的高机位俯瞰整个大厅，缓停 |

路线用 `calibration/path_check.py` 逐帧检查：相机到任何可渲染表面的最近距离 ≥ 0.45 m，不穿模。
改镜头：编辑 JSON 后重新运行脚本；也可以复制成新的 `animations/<名字>.json`，用 `--animation <名字>` 构建。
