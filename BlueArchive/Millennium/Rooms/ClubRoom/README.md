# ClubRoom — 千年科学学园社团活动室（`BG_Milleniumclub`）

参考原画：`Reference/BG_Milleniumclub.webp`（1280 × 900）。
渲染结果：`Renders/BG_Milleniumclub.png`（原画机位），`Renders/BG_Milleniumclub_compare.png`（左渲染 / 右原画），
`Renders/view_*.png`（自由机位验证），`Renders/metrics.json`（数值对比）。

完整场景不进仓库，由脚本生成：在 Blender 里打开并运行 `BlueArchive/build.py`（或 `blender -b -P BlueArchive/build.py`），
得到 `Build/Millennium/ClubRoom/ClubRoom.blend`（git 忽略目录），见仓库根目录 README。

```bash
blender -b -P BlueArchive/build.py -- --render out.png                  # 原画机位
blender -b -P BlueArchive/build.py -- --view reverse --render reverse.png
blender -b -P BlueArchive/build.py -- --render-animation                # 配布视频
```

## 1. 相机解算（摄影测量，不是目测）

原画是两点透视（竖线全部竖直）。流程：LSD 线段检测 → RANSAC 求两个水平灭点 → 竖直方向灭点在无穷远
（俯仰、滚转 = 0）→ 以方形地砖的度量约束解焦距与主点 → 相机高度由桌面高度/地砖尺寸定标。

| 参数 | 值 |
|------|----|
| 焦距 | 1137.1 px（36 mm 画幅宽度下 ≈ 32.0 mm） |
| 主点 | (733.9, 492.56) px → Blender `shift_x = -0.0734`，`shift_y = 0.0333` |
| 朝向 | 偏航 21.412°（看向房间 +Y 并偏向窗侧），俯仰 0，滚转 0 |
| 位置（房间坐标） | (8.04, 6.06, 1.20) m |

`Core/camera.py` 的 `project_points` 与 Blender 渲染的投影一致到 0.01 px；几何对位用
`Core/compare.py` 的叠线图检验（模型轮廓红线 vs 原画边缘青线）。

## 2. 房间（`room.json`，房间坐标：原点 = 玻璃内表面线 × 前墙，+X 向室内，+Y 沿立面）

* 10.5 × 24 m，MIL-A 塔 24 层西立面，房间原点位于塔楼坐标 y = −5.7 m。
* 吊顶：周边跌级 3.96 m，主吊顶 4.2 m，中央灯槽 4.4 m（灯槽矩形、收边条按原画测得）。
* 6 排线性吊灯（z = 3.36 m），后墙洗墙灯，倒梯形全息标牌（上宽 7.57 m / 下宽 6.54 m，校徽与字标按原画轮廓矢量化）。
* 3 个展示书架、6 组桌（左列 0.88 m 宽桌、右列 0.72 m 宽桌，各 3 排），每个座位的椅子颜色/坐垫/微小偏移、
  笔记本与笔筒都写在数据里，并逐一用叠线图对到原画。

## 3. 原画中的"反 3D"结构与处理

原画是手绘，局部透视互相矛盾。原则：**在 3D 里保持建筑上合理、模数一致的设计，在原画机位下尽量贴合**；
不为了贴图而扭曲几何。

| 原画现象 | 处理 | 残差 |
|----------|------|------|
| 窗立柱间距随深度从 1.67 m 递减到 1.36 m（透视不自洽） | 保持 1.5 m 统一幕墙模数，拟合相位：房间沿立面平移 0.3 m（仍在 0.3 m 模数上）；立柱改为 50 × 60 mm 细框（原画线宽只有约 8 px）；原画中的"第 8 根立柱"实为转角柱 | RMS 5.9 px，最大 9 px（原先最大 38 px） |
| 标牌上沿画成水平线（真实透视下应向左下收敛约 22 px） | 标牌为后墙上的真实平面倒梯形，上沿在 3D 中水平 | 两端 ±11 px |
| 左列桌子画得比右列宽 | 两种桌型（0.88 / 0.72 m），3D 中合理 | 对齐 |
| 吊灯排距不均（2.1 → 2.7 m） | 按原画位置布置（灯具间距不均在建筑上可接受） | 对齐 |
| 天空光环是若干组互不同心的同心环 | 在天空中布置 5 组真实的同心环系统（世界坐标），用同心椭圆 Hough 搜索拟合原画的环族，再从相机反投影到 606 m 高度的环平面，倾角由椭圆长短轴比反推；原画最外圈的"环"在正确透视下不存在对应的圆，舍弃 | 主环族与原画重合 |
| 室内阳光方向与窗外楼宇受光方向矛盾 | 只用一个太阳作折中：方位 250°（西南偏西，窗外双塔朝向画面的南立面受光），高度 40°（原画中日照亮带只到离玻璃约 3–4 m，再深入房间的地面在阴影里，由此反推高度角） | 窗边亮带误差 0.31 → 0.10 |
| 窗外比室内曝光"亮一档"（绘画式开窗） | 玻璃与天空只对**相机光线**提亮（`camera_boost`），不改变室内受光；对任何机位一致 | — |

标定脚本：`calibration/fit_halo.py`（光环拟合，`--write` 写回 `campus.json`）；
`verify.py`（渲染与原画的数值对比）。

## 4. 外观（渲染 → 合成）

Cycles，Standard 视图变换；合成器：曝光 → 按原画拟合的全局调色曲线（直方图匹配，`look.grade`）
→ 辉光 → Freestyle 描边（仅房间物体，深蓝色半透明线）。调色是全局的，不依赖画面内容，换机位同样适用。

## 5. 验证（与原画逐像素对比，sRGB 0–1）

最终渲染 `Renders/BG_Milleniumclub.png`（128 spp，调色 + 描边）对原画：

| 指标 | 数值 |
|------|------|
| 全图平均绝对误差 MAE | 0.1040（约 27/255） |
| SSIM（亮度结构相似度） | 0.426 |
| 17 个语义区域平均色差 | 0.0278 |
| 亮度分位 5/25/50/75/95 %（渲染） | 0.368, 0.521, 0.620, 0.737, 1.000 |
| 亮度分位 5/25/50/75/95 %（原画） | 0.379, 0.530, 0.615, 0.758, 0.959 |

区域色差最大的三处：sky_right 0.062；ceiling_back 0.054；sky_upper 0.048。
剩余误差主要是笔触/纹理层面的差异（云朵形状、大理石纹理、窗玻璃上手绘的竖向高光），
不是几何或整体色调的偏差。完整区域表见 `Renders/metrics.json`，可用 `verify.py` 复算。

## 6. 自由机位（`shots/BG_Milleniumclub.json` → `views`）

每个机位可以带自己的 `exposure`（相机曝光，室外机位比室内暗 1–1.5 档），其余外观（调色、描边）与原画机位相同。
这些渲染用来验证：房间在任何角度都是完整、自洽的 3D 空间（家具有背面、墙角闭合、窗外城市与光环在正确的世界位置）。

| 名称 | 内容 |
|------|------|
| `reverse` | 从后墙角看向房间前部（原画看不到的一侧） |
| `window` | 贴近玻璃沿立面看向西北：城市、双塔、光环 |
| `desks` | 桌组之间的视平线 |
| `aerial` | 室外：从西南方看 MIL-A 塔，活动室在西立面 24 层 |

## 7. 配布视频（`animations/Showcase.json`）

`CAM_Showcase`：1920×1080、30 fps、840 帧（28 秒），构建后就是场景的活动相机，Ctrl+F12 直接出片。

| 帧 | 镜头 |
|----|------|
| 1–50 | 与原画完全相同的机位（同焦距、同主点偏移）停留 |
| 50–300 | 推进到桌组之间的过道，对准校徽标牌 |
| 300–540 | 转向窗户，贴近玻璃看窗外：城市、双塔、天空光环（这一段曝光降 0.45 档，像真实相机一样照顾窗外高光） |
| 540–660 | 沿窗边后退，回头看整个房间 |
| 660–840 | 升到前右角的高机位全景，缓停 |

关键帧只写了 9 个（房间坐标系里的相机位置、注视点、焦距、可选主点偏移与曝光），
`Core/anim.py` 用 Hermite 样条计算平滑的贝塞尔手柄：运动连续、在 `ease` 关键帧处缓入缓出，
而且全部是普通关键帧，可以在 Blender 的 Graph Editor / Dope Sheet 里继续调整。
机位路线沿桌组间过道（x 5.04–6.07 m）、窗边通道（x < 2.4 m）走，并保持在吊灯下方（z < 3.36 m），不穿模。
想改镜头：编辑 JSON 后重新运行脚本即可；也可以复制成新的 `animations/<名字>.json`，用 `--animation <名字>` 构建。

渲染时间参考：CPU 上 1920×1080、64 采样每帧数分钟；有 GPU 时快得多。先用
`--render-animation --scale 0.25 --samples 12 --no-lines` 快速试看路线。
